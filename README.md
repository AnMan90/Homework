# Homework

## Описание:

Homework - Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/AnMan90/Homework.git
```
2. Установите зависимости:
```
poetry install
```

## Тестирование

Код проекта протестирован с помощью "Pytest". Отчет о покрытии кода содержится в директории htmlcov.
